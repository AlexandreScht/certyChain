## 🧱 Décisions d'architecture verrouillées

| Sujet | Décision | Pourquoi |
|---|---|---|
| Backend | Hono + TS (Node 22), `/server` | léger, peu coûteux à héberger, durcissable |
| Crypto | Ed25519 + nonce → (phase 2) SnarkJS/Groth16 | MVP shippable ; couture `ProofEngine` |
| DB/ORM | PostgreSQL + Drizzle | typé, migrations versionnées, image légère |
| Auth | JWT cookie httpOnly · scrypt (école, node:crypto natif) · OTP (élève) | sans mot de passe côté élève |
| Secrets | AES-256-GCM enveloppe (KeyVault, KMS-ready) | clés privées écoles jamais en clair |
| Frontend | reste à la racine, 3 portails + verify public | réutilise le design system existant |
| Infra | Docker distroless non-root + compose durci | moindre privilège |
